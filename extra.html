First Time Installation

Fresh setup instructions
01

Flash via Recovery

MicroGPlus should be installed via recovery immediately after installing Custom ROM.

02

Do Not Boot to System Yet

If you reboot into system before installing microG components, you must factory reset and then install them, otherwise expect crashes.

03

Grant Permissions

Rooting via Magisk or KernelSU handles permissions automatically. Otherwise, run the fallback terminal command:

adb shell /system/bin/runtime.sh
Helpful Tip

Always loop back or reboot directly to recovery mode after flashing your Custom ROM for a fresh installation environment.

Module Installation & Compatibility Details

Module installation is back. Same builds can be installed as a Magisk or KernelSU module.

Important Note: Keep in mind, module installation has its own downside. For this reason, we highly prefer installation from recovery like TWRP, LineageOS Recovery, etc. However it is up to you what you want to proceed with. When installed as module, do not enable KSU umount modules option for microG components under App Profile. It will cause crashes and APKs not found.

MicroGPlus includes both functionalities in one package. Perks of module installation, required free space is no longer an issue. You can also remove Google Apps installation. Always survive ROM OTA upgrade with flash and forget experience. Do not disable module, otherwise expect crashes. An edge case for some latest version of KernelSU or forks explained below.

Metamodule Requirements (KernelSU & Forks)

You might need a metamodule installed before installing this as module. Some latest version of KernelSU or forks require metamodule for modules that adds or update files in system without this the module files will not be loaded after reboot. Also when this flashed as module first before flashing a metamodule, this will also cause module files to not load after reboot.

Once a metamodule is installed, it blocks installation of further modules until device is rebooted and metamodule is initialized. This will ensure that the modules depending on the metamodule function properly.

Custom Build Generator

Generate user configured package using the latest Free and Opensource Apps.

You can now build custom MicroG Installer Package with YOUR choice of Free and Opensource Apps with fewer clicks and no creation limits. All packages are built using untouched upstream APK payloads sourced directly from the official microG repository to ensure maximum security and stability. Also these custom builds are securely hosted on a dedicated server. Please visit apilevels.com website to know which Android version goes with which API level.

Core Server Pipeline & Execution
Requirements & Queues You need to use pre-defined options from below to make build request. Enter a username of your choice, it must be exactly seven alphanumeric characters contain only letters and numbers.
Ultra-Fast Delivery Our server CronJob runs after every two minutes. You will get your build done in less than a minute. Build server will now accept all incoming requests and they will be sorted and processed in random order.
Manifest Storage You will also get your folder based on provided username created on server within CronJob time frame. From this folder you can access both older and newer builds. Each build has its own text file containing list of free and opensource apps added in that specific package.
Storage & Lifespan Once disk space of the build server reaches a critical level, previous builds will be removed including folder based on the provided username to maintain performance.
